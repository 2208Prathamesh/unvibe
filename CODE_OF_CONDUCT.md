# Contributor Covenant Code of Conduct

## Our Pledge
We pledge to make participation in **Unvibe** a respectful, welcoming experience for everyone regardless of background or experience level.

## Expected Behavior
- Communicate constructively and politely in issues, pull requests, and reviews.
- Focus feedback on visual craft, accessibility, code clarity, and documentation.
- Respect the repository's MIT License and contributor guidelines.

## Unacceptable Behavior
- Harassment, personal attacks, trolling, or discriminatory language.
- Publishing private user information without permission.

## Enforcement
Repository maintainers may remove, edit, or reject contributions or comments that violate this standard.
