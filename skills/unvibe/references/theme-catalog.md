# Unvibe Theme Catalog (24 Themes Across 6 Packs)

All 24 themes include both **Light** and **Dark** WCAG AA contrast-verified palettes, webfont pairings, geometry rules, motion timings, and do/don't guardrails. Query `unvibe-mcp` (`list_themes`, `recommend_themes`, `get_theme`, `generate_tokens`) to inspect or scaffold any theme.

## 1. Everyday Apps (`everyday-apps`)

| Theme ID | Default | Surface & Craft DNA | Best For |
| :--- | :--- | :--- | :--- |
| `graphite-studio` | Dark | Neutral graphite steps, 1px hairlines, one crisp cobalt signal, Inter + JetBrains Mono | SaaS dashboards, analytics suites, admin portals |
| `ash-dialogue` | Dark | Matte charcoal dialogue layers, wide reading stream, restrained emerald accent | AI assistants, chat workspaces, prompt consoles |
| `parchment-editorial` | Light | Warm archival cream paper, Newsreader serif titles, terracotta signal | Writing tools, intelligent readers, journals, notes |

| `tonal-workspace` | Light | Cool daylight tonal elevation, full-pill global search and active nav pills | Mail clients, drives, calendars, doc suites |
