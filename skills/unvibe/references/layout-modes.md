# Layout Proportions & Surface Modes

Scale visual ambition, density, and structure to the job the screen performs.

## 1. The Five Surface Modes

| Mode | Examples | Density & Restraint | Where Color & Craft Live |
| :--- | :--- | :--- | :--- |
| **Operate** | Dashboards, editors, chat consoles, admin apps | Compact to comfortable; chrome stays quiet so hours of use cause zero fatigue | Status deltas, single primary action, focal chart, real data tables |
| **Read** | Docs, wikis, blogs, essays, changelogs | Comfortable prose measure (`62–72ch`), high line-height (`1.55–1.65`), subtle dividers | Crisp typographic hierarchy, code blocks, pull quotes |
| **Persuade** | Product landing pages, launches, pricing | Spacious vertical rhythm (`80–128px` section gaps), strong hero composition | One unforgettable hero visual or live product view + clean asymmetric split |
| **Social** | Feeds, galleries, directories, communities | Media-first proportions; fixed aspect containers; 44px mobile touch controls | User photography, avatars, crisp engagement states |
| **Editorial** | Publications, exhibitions, luxury lookbooks | Generous negative space, ruled columns, classical display-to-body contrast | Photography scale, serif rhythm, double hairline rules |

## 2. App & Dashboard Proportions (`Operate`)
- **Full-viewport shell:** Sidebar `240–280px` wide + fluid main area capped at `1440–1600px` with `24–32px` page padding. Never shrink a desktop dashboard into a narrow centered column.
- **Navigation density:** Sidebar rows `32–36px` tall, `2–4px` gap between rows, `16px` icon box aligned in a single vertical column, section headings spaced `24px` above and `8px` below.
- **Stat card discipline:** Compact stat cards show Label + Tabular Value + Compared Delta (`+12% vs last month`). Do **not** jam sparklines or progress rings into every stat card.
- **Chart hierarchy:** One primary focal chart (`280–360px` tall, spanning at least 2/3 width) paired with a narrow ranked list or table—never two identical side-by-side charts.

## 3. Landing Page & Hero Composition (`Persuade`)
- **Above the fold (`1280x800`):** Headline, one concise sentence, primary CTA (+ at most one quiet secondary CTA), and the hero visual or product preview must read cleanly without scrolling.
- **Avoid stacked-center defaults:** Prefer an asymmetric split (headline + actions on left, product/visual spanning `>=50%` width on right) or display headline rising cleanly into a crisp product view anchored at the bottom edge.
- **Section rhythm:** Vary layout shapes across consecutive sections (e.g., asymmetric split -> ruled comparison -> wide interactive demo -> single focused closing action). Never repeat identical 3-card-icon-grid rows back to back.
- **Closing action:** End on what the visitor actually came to do (sign in, install CLI, book, calculate, start), not an unsolicited newsletter signup form.
